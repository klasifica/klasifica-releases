# Klasifica — Android Releases

Este repositorio contiene las versiones oficiales de la **app Android de Klasifica**, disponibles para descarga directa (sideload).

## Descargar la app

1. Ve a la sección [**Releases**](https://github.com/klasifica/klasifica-releases/releases)
2. Descarga el archivo `.apk` de la versión más reciente
3. En tu Android: **Ajustes → Seguridad → Instalar apps de fuentes desconocidas** ✓
4. Abre el `.apk` descargado e instala

## ¿Qué es Klasifica?

Klasifica es una plataforma de gestión de competiciones deportivas. Esta app permite a árbitros, jugadores y aficionados seguir partidos en tiempo real.

## Instalación automática desde la app

Si accedes a [app.klasifica.com](https://app.klasifica.com) desde Android, encontrarás un banner de descarga que te llevará directamente al APK más reciente.

## Versiones

Cada release incluye:
- Número de versión
- APK firmado y optimizado
- Instrucciones de instalación
